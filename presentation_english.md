# Slide 2: Background
### Business Challenge
Workshop operations often face several issues:
- Manual customer data management
- Difficult vehicle tracking
- Unstructured service records
- Slow response to customer requests
- Limited visibility into repair history and spare parts needs

These problems can reduce efficiency, increase human error, and slow down service quality.

# Slide 3: Project Objectives
The main objectives of this project are to:
- Automate customer and vehicle data management
- Provide a digital system for services and repairs
- Integrate AI capabilities for customer interaction
- Improve operational efficiency in workshop management
- Support future expansion with scalable backend architecture

# Slide 4: Solution Overview
This project introduces an intelligent workshop management system that combines:
- AI agent for conversational support
- Customer, vehicle, and service management modules
- REST API backend
- Web-based frontend dashboard
- Database system for storing operational data

The system enables workshop staff and customers to access information more quickly and reliably.
